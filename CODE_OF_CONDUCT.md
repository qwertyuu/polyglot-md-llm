# Code of Conduct

We want Polyglot PMD to be a precise, constructive, and welcoming project.

Contributors and maintainers are expected to:

- discuss ideas and code without personal attacks;
- give actionable technical feedback and accept it in good faith;
- respect different backgrounds, identities, and levels of experience;
- avoid harassment, discrimination, doxxing, and unwanted sexual attention;
- keep project spaces focused on improving the software and its community.

Maintainers may edit or remove contributions that violate these expectations and
may temporarily or permanently restrict participation. Report conduct concerns
privately through GitHub's repository contact mechanisms. Maintainers will
handle reports as confidentially and impartially as practical.
